# Event posters

Static event poster landing page for NALICO and NAFICO.

## Current status

The initial page is a coming-soon page. The event name and three final poster files have not yet been supplied. No event details or poster artwork have been invented.

## GitHub Pages setup

Repository: `densdanielp-max/event-posters`.

1. Publish this folder's files to the repository's `main` branch.
2. In repository Settings > Pages, select Deploy from a branch, `main`, and `/ (root)`.
3. Verify the public URL provided by GitHub before generating the final QR code.

Expected project URL, subject to the actual repository and Pages configuration: `https://densdanielp-max.github.io/event-posters/`.

## Add the posters

Store the three approved poster files in an `assets` directory and update `index.html` with their real titles, previews, and view/download links. Keep the repository name and public page URL stable so the printed QR remains usable after content updates.

Only public event materials belong in this repository.
